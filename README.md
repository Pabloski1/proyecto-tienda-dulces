# Proyecto: Carrito de Compras "Dulce Tentación"

Este es un proyecto universitario desarrollado en Python que simula el sistema de carrito de compras de una tienda.

## Descripción

El script presenta al usuario un menú de categorías de productos (Dulces, Salados, Helados, Colaciones) y permite seleccionar múltiples artículos, especificar cantidades y agregarlos a un carrito.

Al finalizar la compra, el sistema solicita datos del cliente y calcula el costo total, aplicando una serie de descuentos basados en la cantidad de productos, la forma de pago y si se compraron artículos de todas las categorías.

## Funcionalidades Principales

* Navegación por un inventario de productos anidado (diccionarios de Python).
* Gestión de un carrito de compras dinámico.
* Cálculo de subtotales y total final.
* Aplicación de lógica de descuentos complejos.
* Generación de una factura de compra simulada.

## Tecnologías Utilizadas

* **Python:**
    * Estructuras de datos (Diccionarios anidados, Listas).
    * Bucles `while` y condicionales `if/else`.
    * Manejo de entrada (input) del usuario.
